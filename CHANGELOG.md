# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `fetchTransactions(accountId:dateStart:dateEnd:status:)` — bank transactions of any status; `.all` merges a separate uncategorized fetch to work around Zoho's `Status.All` listings excluding uncategorized statement lines
- `ZBTransactionStatusFilter` enum for `filter_by` values
- `fetchExpense(expenseId:)` detail fetch exposing attached documents (`ZBDocument`)
- `fetchExpenses(dateStart:dateEnd:)` date-range listing
- Generic pagination (`fetchAllPages`): every list endpoint now pages to completion (invoices, payments, chart of accounts, items, taxes previously truncated at one page) and checks the Zoho envelope code

### Fixed
- 429 handling no longer retries forever: after a bounded number of 60s waits (default 2) the request throws `HttpServiceError.rateLimited`. Previously a client that hit Zoho's *daily* API quota would silently hang in a retry loop until the quota reset.

### Changed
- `searchContactByName` filters server-side (`contact_name_contains`) instead of downloading the whole contact list
- OAuth token refresh sends credentials in the form-encoded POST body instead of the URL query string
- Test suite converted from XCTest to Swift Testing; package requires swift-tools-version 6.0 (targets stay in Swift 5 language mode)
- `ZohoBooksClient.xcodeproj` is no longer tracked (it's regenerated by Tuist when consumed as a local dependency)

### Documented
- Live-verified Zoho API quirks: `Status.All` hides uncategorized lines; `date_start`/`date_end` ignored on transaction listings; uncategorized lines are excludable but not deletable via API (see README)

## [0.1.0] - 2026-01-20

### Added
- Initial release
- Zoho Books API client with async/await support
- OAuth authentication with token refresh
- Support for all Zoho regions (US, EU, IN, AU, JP)
- Models for contacts, invoices, expenses, payments, items, taxes, and accounts
- Rate limiting and error handling
- Multipart file upload support
